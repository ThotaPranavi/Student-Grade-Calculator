The Student Grade Calculator is a Java application that calculates a student's total marks, average percentage, and grade based on marks entered for multiple subjects.
Features
Enter marks for multiple subjects
Calculate total marks
Calculate average percentage
Assign grades automatically
Display complete result summary
Input validation
